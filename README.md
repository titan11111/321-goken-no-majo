# 剛拳の魔城 — IRON / HEX

魔力ゼロの石工ガルドが、魔王ヴェルグの城へ挑むベルトスクロールアクション。

**index.htmlだけで動作します。** ブラウザで開くか、Webサーバーから配信してください。外部ファイル、通信、インストールは不要です。iPhoneはSafariでのHTTP配信を推奨します。

## 操作

| 操作 | タッチ | キー |
|---|---|---|
| 移動・奥行き移動 | 左パッド | WASD / 矢印 |
| パンチ3連撃 | 拳（長押し可） | J / Z |
| キック3連撃 | 脚（長押し可） | K / X |
| 無敵ステップ | 方向＋回避 | Space / L |
| 闘気の震撃 | 震撃（闘気100） | U / C |
| 一時停止 | 右上Ⅱ | P / Esc / Enter |
| 音の切替 | 右上♪ | M |

パンチ：左ジャブ→右ストレート→両手パンチ。キック：右→左→ドロップキック。
3撃目で結界を破壊し、目前の魔法弾を反射できます。魔王の金色の結界中は詠唱が中断しにくく、足元の予告を避ける必要があります。

2026-10-11改修：筋肉と衣服を描き込んだ主人公30ポーズ、魔法使い・魔王、4種類の背景を同梱。入力イベント内で攻撃を開始し、命中演出中も回避可能。

4エリア・6戦闘区間。途中敗北はその区間から再挑戦。鍛錬場、難易度、左利き配置、パッド感度、軽い演出、画質設定に対応。

## 開発資料

- SPEC.md：批評とゲーム構成
- TECHNOLOGY.md：既存コードの抽出元、2026-10-10の一次資料と採用判断
- VERIFICATION.md：検査結果と確認できていない範囲
- ARTWORK.md：生成方法・採用素材・最終プロンプト
- LEARNINGS.md：検査で見つけた問題と修正
- src/belt-core.js：抽出したベルトスクロールの基盤

編集はsrc/、成果物はindex.html。親リポジトリの共通CSSがある環境で `python3 build.py` を実行すると再生成できます。
