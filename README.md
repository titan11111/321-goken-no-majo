# 闘え！石工ガルド — GARUD / RESISTANCE

魔力ゼロの石工ガルドが、拳ひとつで魔王の呪いに挑む。石にされた街を取り戻す全12エリア・48戦闘区間、二面構成のベルトスクロールアクション。

**index.html、assets/ のWebP画像、audio/ のBGM 4曲で動作します。** 3つを同じフォルダ構成に置き、Webサーバーから配信してください。画像は別ファイルで読み込むため、HTML本体の転送量を約2.1MB抑えています。iPhoneはSafariでのHTTP配信を推奨します。

## 操作

| 操作 | タッチ | キー |
|---|---|---|
| 移動・奥行き移動 | 左の十字キー | WASD / 矢印 |
| パンチ3連撃 | Aボタン（長押し可） | J / Z |
| キック3連撃 | Bボタン（長押し可） | K / X |
| 無敵ステップ | 方向＋SELECT（回避） | Space / L |
| ジャンプ（空中で拳＝ジャンプパンチ／脚＝飛び蹴り） | 跳（A/Bの上） | I / V |
| 闘気の震撃 | START（震撃・闘気100） | U / C |
| 一時停止 | 右上Ⅱ | P / Esc / Enter |
| 音の切替 | 右上♪ | M |

パンチ：左ジャブ→右ストレート→両手パンチ。キック：右→左→ドロップキック。
3撃目で結界を破壊し、目前の魔法弾を反射できます。魔王の金色の結界中は詠唱が中断しにくく、足元の予告を避ける必要があります。

2026-10-11改修：筋肉と衣服を描き込んだ主人公30ポーズ＋歩行8コマ、女性3種を含む敵7種の外見、8種類の背景を同梱。入力イベント内で攻撃を開始し、命中演出中も回避可能。

一面の魔王を越えると二面へ突入し、呪いの核を破壊して完結。途中敗北はその区間から再挑戦。鍛錬場、難易度、左利き配置、パッド感度、軽い演出、画質設定に対応。

## 開発資料

- SPEC.md：批評とゲーム構成
- TECHNOLOGY.md：既存コードの抽出元、2026-10-10の一次資料と採用判断
- VERIFICATION.md：検査結果と確認できていない範囲
- ARTWORK.md：生成方法・採用素材・最終プロンプト
- LEARNINGS.md：検査で見つけた問題と修正
- src/belt-core.js：抽出したベルトスクロールの基盤
- src/fx.js：魔法弾・詠唱・着弾・光柱の描画（スプライト事前生成）／src/music.js：BGM切替
- src/art-baked.json：画像の切り出し範囲（起動時の計測を廃止し、ビルド時に固定。再生成は _playtest/bake-art.mjs）

配信成果物はindex.htmlとassets/です。現在のsrc/は直近のindex.html改修と同期していないため、`python3 build.py` は安全のため停止します。`--force` で実行するとゲームの改修を上書きするため、src/を同期するまでは実行しないでください。

## 2026-10-11 物語・テンポ改修

- 約19秒のSFパンク調オープニング。操作説明なし。SKIP / Escで即開始、「次回から省略」と設定のON/OFFを保存。
- 歩行専用8コマ（透明WebP）を追加。移動距離から脚の接地・交差・踏み出しを切り替える。
- 全滅後の長い移動待ちを廃止。前進すれば最短約0.38秒、止まっていても約0.85秒で次の戦闘へ。次区間に古い震撃・魔法を持ち越さない。
- 闘気の獲得量を4倍（通常命中24／強打52、上限100）。鍛錬場の自動回復も4倍。震撃自身の命中では再充填しない。
- 命中音に割れる高音と低い衝撃を追加。「バキッ」「ドカッ」「ドガッ！」の文字を命中位置に表示。音量のピークを圧縮。
- 石化が解ける結末をエンディングへ接続。

追加検証: `_playtest/revision-check.mjs`。実機での音の聞こえ方・操作感は未確認。

## 2026-10-11 被弾・女性キャラクター・道中拡張

- 主人公は被弾方向へののけぞり、腹をかばう姿勢、踏ん張りと復帰。敵は通常打撃と強打で反応量を変える。操作不能時間を演出の長さに合わせて延ばさない。
- 女性3種を追加：紅蓮の魔女（炎）、蒼氷の魔女（速い氷弾）、翠盾の女騎士（盾・近接）。各3姿勢（待機／詠唱・攻撃／被弾）、独自の詠唱台詞、名前表示。
- 道中は石化した街 → 城外橋 → 地下水路 → 灰の回廊 → 月下の庭園 → 禁書庫 → 封印の門 → 魔王の玉座。全10戦闘、敵27体のうち女性の外見を持つ敵は15体。
- 街の石像から始まり、禁書庫で呪いの源を確かめて魔王へ進む。約0.85秒の戦闘間進行と4倍ゲージは維持。
- 被弾と場面の検証：`_playtest/expansion-check.mjs`。スマートフォン画面のChromium/WebKitで確認。iPhone実機は未確認。


## 2026-10-12 二面・巨人草・石工モード改修

- 一面8エリアを越えると、背景4種を追加した二面へ進む。全12エリア・48戦闘区間で呪核の間の魔王を倒す構成。
- 巨人草を使うと画像が上空から降り、点滅して消えた後に巨大化。巨人時の移動速度を20%上げ、通常ジャンプの高さを約2倍にした。
- 石工モードは実写風の大理石彫像へ差し替え、審査員をコブシデス、イシノマニア、ガルドの父に変更。
- FPS自動画質調整は55FPSを下回る状態で早めに解像度を落とし、安定して58FPSを超えると段階的に戻す。
